# ae5vg.com

Static showcase site for AE5VG software: fldigi-mcp, wsjtx-mcp, n3fjp-mcp, mcp-host-bridge, the Operating Field Guide and the QSO resolver project. Plain HTML and CSS, no build step. Served by GitHub Pages from the `main` branch; `CNAME` holds the custom domain.

Preview locally:

    python3 -m http.server 8791
